# Sonamu BookEditor OCR (소나무 북에디터 OCR)

소나무디자인 출판 전문 디자이너를 위한 고정밀 한글 도서 본문 OCR 및 교정 전용 데스크톱 애플리케이션입니다.

## 주요 기능
- **AI 비전 엔진**: Google Gemini 최신 Flash-Lite 모델 연동 (대용량 쿼터 및 실시간 OCR)
- **맞춤법 및 교정**: 한국어 전문 출판 교정 규칙 및 문맥 복원
- **자동 업데이트 시스템**: GitHub Releases 연동 원클릭 자동 덮어쓰기 패처 (기존 사내 기기 인증 보존)
- **인디자인 원클릭 연동**: 클립보드 자동 복사 및 즉시 편집 창 제공
